# Approved fonts

Permitted font families:
- Inter
- Noto Sans
- Noto Sans Arabic
- Roboto

Rules:
- Only these families may be referenced in application source, stylesheets,
  design tokens, component libraries, or bundled font assets.
- Flag remote font imports and local font files unless the family is approved.
- Treat aliases and spelling variants as the same family where evident.
- Report the file, line, detected font, and permitted alternatives.
